# iKuuu

使用浏览器现有登录态完成每日签到，并领取网站提供的流量奖励。

## 使用前准备

在安装并连接 OpenCLI Browser Bridge 扩展的浏览器中登录 [iKuuu 用户首页](https://ikuuu.top/user)，确认能看到“每日签到”或“明日再来”。运行 `opencli doctor` 检查连接；多个浏览器配置同时连接时，使用 OpenCLI 的 `--profile` 选择已登录的配置。

命令不接收或保存账号密码、Cookie；登录过期时需先在浏览器重新登录。遇到验证码或访问验证，需要在浏览器人工完成。标签页的 `sessionStorage` 必须可用，命令在其中保存一个不含凭据的尝试标识，以阻止连接重试造成重复提交。

## 命令

```bash
# 完成当天签到
opencli ikuuu checkin

# 获取结构化结果
opencli ikuuu checkin -f json
```

| 字段 | 含义 |
| --- | --- |
| `status` | `success`：本次签到已通过刷新核验；`already_checked_in`：今天已经签到 |
| `message` | 网站返回的奖励说明，或“今日已签到，明日再来。” |

当天已签到时直接返回，不重复提交。未签到时只触发一次网站原有按钮，读取该次响应，然后重新加载首页确认服务器显示已签到。仅出现成功弹窗或按钮改变，不足以判断成功。

更新后的 Browser Bridge 默认复用已有普通窗口，在独立后台标签中执行签到，临时会话结束后关闭任务标签，不覆盖你已打开的页面。没有可用普通窗口时才创建专用窗口；显式使用 `--window foreground` 也保留专用窗口。修改扩展后需在浏览器扩展管理页重新加载，才能启用新行为。

## 失败处理

登录失效使用 `AUTH_REQUIRED`（退出码 77）；等待响应超时使用 `TIMEOUT`（75）；页面变化、验证码、请求失败或刷新无法确认使用 `COMMAND_EXEC`（1）。失败不会返回成功记录。

提交后遇到超时或连接中断，服务器可能已经完成签到。命令不会自动再次提交：请先在浏览器刷新用户首页核对，显示“明日再来”代表今天已签到。

本适配器仅支持 `ikuuu.top` 的当前签到页面，不包含自动登录、多账号轮询或每日定时任务。自动测试使用合成页面，不触发线上签到。
